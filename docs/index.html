“Previous cup” can refer to retained evidence, even when the current frame is blank. A new query supersedes an older pending turn.

Controlled transformations of a CC0 photograph; not human interaction footage. Queries use a finite grammar. Responses are grounded templates with an injected 400 ms delay, not LLM outputs. The replay shows sampled frames from a local run.

02

Measure the waiting, too.

A faster answer is useful only when its evidence is still relevant.

Three runs per policy, 240 input frames per run, 30 fps, capacity 4, YOLOX-s FP32, two CPU threads, Apple M4 Pro. These measurements describe this workload and machine; they do not measure interaction accuracy. Inspect raw traces ↗

03

A compact runtime.
A deliberate boundary.

01 / ACQUIRE

Observe continuously.

Frame ownership, source clocks and bounded queues keep capture separate from model inference.

02 / ASSOCIATE

Retain the evidence.

Local object tracks and bounded snapshots distinguish what is visible now from what was observed earlier.

03 / RESPOND

Check before publishing.

Turn, age and target checks suppress superseded or stale answers. Ambiguous references request clarification.

Implemented now

Actual object detection · bounded concurrency · finite reference queries · trace replay · response validation
